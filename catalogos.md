# Catálogos — Análisis UX (perspectiva de usuario)

**Fecha:** 26 de mayo de 2026

Resumen: listado de valores de catálogo (document types, identificaciones) con estado Global/Activo.

Hallazgos (usuario):
- Identificadores largos (UUID) mostrados junto al nombre del valor ocupan espacio y aportan poco al usuario final.
- Falta acción rápida para editar/ocultar valores en línea; la interfaz obliga a scroll para acciones frecuentes.
- Badges "Activo"/"Global" con contraste muy bajo en algunos temas.

Recomendaciones:
- Ocultar UUIDs por defecto y ofrecer un toggle "mostrar ID" para admins.
- Añadir acciones inline (editar, activar/desactivar) y paginación para listados largos.
- Aumentar contraste de badges y seguir sistema de tokens de color accesible.

Prioridad: baja.
